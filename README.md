# 面談日程づくり

家庭訪問・個別懇談の日程を、保護者の希望（○×）から決めて、日程表と連絡帳用のお知らせを作るWebアプリです。

▶ https://iamochiai-collab.github.io/Kondan/

## 個人情報について

- **このアプリは、ブラウザの中だけで動きます。** 入力した名前や希望は、使っているパソコンのブラウザの中にだけ保存されます。
- インターネット上（サーバーやクラウド）には**送られません**。アプリを作った人を含め、ほかの人が見ることはできません。
- 文字の形や、PDFを作るための部品を読み込むときだけインターネットにつながりますが、入力した内容は送りません。
- 共用のパソコンでは、使い終わったら右上の「リセット」→「ぜんぶ消す」で消してください。
- 「保存・読み込み」で作ったファイルや、印刷・PDF・Wordは、ふつうの書類と同じように、校内の決まりにそって扱ってください。

## 使い方

### 1. 名前と先生
- クラス名（例：1年1組）と、先生の名前（名字だけでOK）を入れます。
- 児童生徒の名前を1行に1人ずつ入れて「まとめて追加」。Excelの「番号」「名前」の列を貼り付けることもできます。
- 一覧の右側で「主に話す先生」と「同席する先生」を選びます。

### 2. 日にちと時間帯
- 題名（個別懇談・家庭訪問など）と、日にちを入れます。
- 時間帯は、最初は13:00～16:30（30分ごと）が入っています。「まとめて作る」で15分ごとなどに作り直せます。
- 会議などで入れない時間は、下の表で「ー」にします。

### 3. 希望の入力
- 最初はぜんぶ×です。保護者が来られる時間帯のマスを押して○にします（なぞってもOK）。
- キーボードの ← → で前後の人へ、Enter で次の人へ。「前の人と同じにする」も使えます。
- 「全員の○×」では、クラス全員の希望を1枚の表で見たり、直したりできます。
- きょうだいがいる人、2コマ続けてとりたい人、時刻が決まっている人は、下の欄で設定します。

### 4. 日程の調整
- 「自動で入れる」を押すと、希望・きょうだい・使わない時間を考えて、全員の日程を入れます。
- 表のマスの緑の名前は、その時間帯に○の人です。押すと、その人に決まります。
- マスの「＋」から、×の時間帯に入れることもできます。
- 魔法のステッキは自動で入れた人、画びょうは手で決めた人です。手で決めた人は、自動で入れ直しても動きません。

### 5. 印刷・保存
- **日程表と希望の集約表**：先生用の表です（白黒・教科書体）。
- **保護者へのお知らせ**：A4に8人分。切って連絡帳に貼ります。文面は画面で直せます（個別懇談・家庭訪問で別々）。
- 「印刷ページを開く」から印刷できます。印刷の画面で「PDFに保存」も選べます。Word・Excelでも出せます。

### こまったときは
- まちがえたときは、右上の「もどす」で、ひとつ前にもどせます。
- 別のパソコンで続けるときは「保存・読み込み」でファイルに保存して、そのファイルを読み込みます。
